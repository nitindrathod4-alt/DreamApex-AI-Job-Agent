# DreamApex AI – Job Search & Application Agent

AI-powered job search, matching, resume optimization, cover-letter generation, and interview preparation platform.

## Architecture
- React + Vite frontend
- FastAPI backend
- AI agent service layer
- PostgreSQL + Redis
- Docker Compose
- Kubernetes starter manifests

## Development
Run the complete local stack with:

```bash
docker compose up --build
```

Frontend: http://localhost:5173
Backend docs: http://localhost:8000/docs

Final application submission remains under user control.
